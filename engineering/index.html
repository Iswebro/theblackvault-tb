Control Plane and Git Pack Ledger

An AI-operations governance architecture for Nexus: a dual-surface control-plane contract designed to remove a single-connector point of failure, append-only Git evidence ledgers for executor reports and side-quest completion packs on dedicated never-merged refs, a seven-state fail-closed activation lifecycle in which every promotion is a separate human gate, and an independent reviewer that re-derives every claim from committed evidence.

Precise status: merged into Black Vault Nexus develop by true merge commit 981ce13d on 2026-07-23 (PR #669) — a documentation and governance implementation only. Not on main, not operational; the Git recovery projection is proposed and inactive, and no runtime, database, provider, scheduler or deployment activation occurred. The Nexus repository is private — the PR link is an exact locator for reviewers with access, while the audited PDF is public.
